# Política de validação técnica

Antes de qualquer uso profissional, cada módulo de cálculo deverá ter:

- objetivo e domínio de validade definidos;
- unidades, convenções e hipóteses documentadas;
- referências técnicas e edição confirmadas;
- testes de casos nominais, limites e entradas inválidas;
- comparação com exemplos publicados ou cálculo independente;
- revisão por profissional habilitado;
- relatório de limitações e versão do módulo.

A existência de testes de software não prova, isoladamente, que um método de engenharia está correto. O projeto inicial não realiza dimensionamento normativo completo.
