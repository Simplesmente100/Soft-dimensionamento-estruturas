# Plano de desenvolvimento

Este roteiro é uma proposta inicial; cada etapa deve ser validada antes de iniciar a seguinte.

## Etapa 1 — Fundamentos
- [x] Criar pacote Python e configuração de testes.
- [x] Implementar exemplo de propriedade geométrica com testes.
- [ ] Definir unidades, convenções de sinais e política de precisão numérica.
- [ ] Estabelecer revisão de código e integração contínua.

## Etapa 2 — Geometria
- [ ] Modelar águas, inclinações, vãos e beirais.
- [ ] Representar tesouras, terças, caibros, ripas e ligações.
- [ ] Validar a geometria com exemplos independentes.

## Etapa 3 — Ações e análise
- [ ] Especificar entradas de peso próprio, cobertura, manutenção e vento.
- [ ] Definir combinações aplicáveis a partir de referências técnicas confirmadas.
- [ ] Escolher e validar métodos de análise estrutural.

## Etapa 4 — Verificações de madeira e ligações
- [ ] Identificar normas brasileiras vigentes e fontes licenciadas/acessíveis.
- [ ] Documentar propriedades dos materiais e condições de serviço.
- [ ] Implementar verificações em módulos isolados com casos de referência.
- [ ] Realizar revisão independente dos resultados.

## Etapa 5 — Saídas profissionais
- [ ] Quantitativos de materiais com rastreabilidade.
- [ ] Relatórios com entradas, hipóteses, unidades e memória de cálculo.
- [ ] Exportação de desenhos e formatos interoperáveis.
- [ ] Interface gráfica após estabilização do núcleo de cálculo.

## Critérios para liberar cálculos
Nenhum módulo normativo deve ser considerado pronto sem fonte técnica identificada, testes automatizados, comparação independente e revisão por profissional habilitado.
